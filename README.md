# Pose Runner 🏃‍♂️💨

**Pose Runner** 是一款結合網頁前端技術與人工智慧的體感跑酷遊戲！玩家不需要使用鍵盤或搖桿，而是必須透過電腦的視訊鏡頭（Webcam）做出特定的真實動作，才能讓遊戲中的角色順利跨越重重障礙。

這個專案的誕生，展示了如何快速將瀏覽器技術與輕量級的 AI 模型結合，創造出有趣的互動體驗。

---

## 🛠️ 技術組成與開發背景

本遊戲的開發與架構主要由以下兩大核心推動：

1. **Jules (AI 開發助手)**
   * 本專案的程式碼（包含 HTML5 Canvas 遊戲引擎、UI 介面、邏輯判定）完全由 AI 軟體工程師 **Jules** 協助使用者從零到有規劃並實作完成。
   * 使用純粹的 Vanilla JavaScript、HTML 與 CSS 撰寫，無需依賴繁重的框架，確保遊戲在瀏覽器上能輕量、流暢地執行。

2. **Google Teachable Machine 🧠**
   * 遊戲的「眼睛」來自於 [Google Teachable Machine](https://teachablemachine.withgoogle.com/)。
   * 玩家可以自己錄製並訓練一個姿態辨識（Pose Recognition）模型。
   * 透過引入 `TensorFlow.js`，遊戲能即時讀取 Webcam 畫面，並將使用者的動作轉化為遊戲指令（例如：偵測到「蹲下」，遊戲角色就會縮小判定框閃避雷射）。

## 🎮 遊戲玩法

遊戲的節奏類似於經典的 Chrome 恐龍跑酷，但挑戰在於你的「姿勢」必須隨機應變！

### 操作方式
1. 確保你的瀏覽器允許存取攝影機。
2. 進入遊戲後，你可以先看著畫面左下方的 **「Current Pose Detected」** 來測試你的姿勢是否被正確辨識。
3. 點擊 **Start Game**（或按空白鍵）開始。
4. 當不同顏色的障礙物靠近時，做出對應的姿勢以安全通過：
   * ⬜ **正常站立 (Stand / Normal)**：無障礙物時的預設狀態。
   * 🟦 **藍色低空雷射** $\rightarrow$ 做出 **蹲下 (Duck)** 的姿勢。
   * 🟥 **紅色高牆手印** $\rightarrow$ 做出 **雙手舉高 (Rise Hand)** 的姿勢。
   * 🟩 **綠色狹窄通道** $\rightarrow$ 做出 **單腳站立 (Lift Leg)** 的姿勢。
5. 只要你的姿勢與障礙物要求的姿勢相符，即可安全穿透並獲得分數！

*(註：如果你沒有視訊鏡頭，遊戲也支援「鍵盤模擬模式」，你可以按下 `N`, `D`, `H`, `O` 來模擬這四種姿勢變化)*

## ⚙️ 遊戲設計機制

* **即時姿態推論 (Real-time Inference)**：遊戲的 `requestAnimationFrame` 迴圈被分為「畫面渲染」與「模型推論」兩條處理線。即使模型推論需要一點時間，遊戲畫面依然能保持流暢。
* **動態難度 (Dynamic Difficulty)**：遊戲內建動態加速機制。隨著玩家分數越來越高，障礙物的移動速度會逐漸加快。玩家也可以透過下方的 **Game Speed** 滑桿，隨時手動調整遊戲的初始速度。
* **彈性的防呆判定**：為了彌補人類動作與網路攝影機的延遲，遊戲的碰撞判定採用「狀態對齊」機制。只要在角色與障礙物重疊的瞬間，你的「姿勢標籤」是正確的，系統就會判定你成功閃避。
